## Что это?

Clawd Pet - это интерактивный виртуальный питомец для Android, который живёт прямо на экране твоего смартфона! Он гуляет, прыгает, ест, спит и реагирует на твои действия.

<div align="center">

### Основные возможности

</div>

| Функция | Описание |
|---------|----------|
| **Свободное передвижение** | Питомец самостоятельно гуляет по экрану |
| **14 цветовых схем** | От классического Claude до снежного белого |
| **10 аксессуаров** | Шапочки, очки, наушники, корона и другое |
| **Система голода** | Корми питомца, чтобы он был счастлив |
| **Реплики и эмоции** | Более 50 фраз и анимированных эмоций |
| **Датчики** | Реакция на наклон телефона и тряску |
| **Режим сна** | Питомец засыпает когда устаёт |
| **Гравитация** | Ходит по нижней части экрана или летает свободно |

## Возможности

### Персонализация
- **14 уникальных расцветок**: Claude, Мятный, Лавандовый, Небесный, Розовый, Графит, Золотой, Коралловый, Изумруд, Снежный, Ночной, Пламя, Океан, Сирень
- **10 аксессуаров**: Шапочка, Кепка, Очки, Тёмные очки, Нимб, Бабочка, Корона, Наушники, Цветок
- **4 размера**: От маленького до огромного
- **Настраиваемое имя**: Назови питомца как хочешь

### Взаимодействие
- **Тап**: Питомец прыгает и реагирует
- **Двойной тап**: Высокий радостный прыжок с искрами
- **Удержание**: Гладь питомца и получай сердечки
- **Перетаскивание**: Перемещай питомца по экрану
- **Тряска телефона**: Питомец закружится

### Система питания
- **Автоматическое появление еды**: Настраиваемая частота (редко/обычно/часто)
- **Три типа еды**: Печенье, рыба, обычная еда
- **Индикатор голода**: Анимированная иконка над головой
- **Ручное кормление**: Кнопка в уведомлении

### Настройки поведения
- **3 скорости**: Спокойный, Обычный, Шустрый
- **Режим гравитации**: Ходит по полу или летает свободно
- **Автономное блуждание**: Включи/выключи самостоятельные прогулки
- **Реакция на датчики**: Наклон и тряска телефона
- **Упрямство**: Питомец может сопротивляться перетаскиванию
- **Режим сна**: Через 1/3/10 минут или никогда

### Фразы и эмоции
- **Более 50 уникальных фраз** на разные ситуации
- **Настраиваемая частота**: Редко, Иногда, Часто
- **Эмоции**: Счастье, злость, удивление, любовь, грусть, головокружение
- **Анимированные частицы**: Сердечки, искры, звёзды, zzz, капли, ноты

## Установка

### Готовый APK
1. Скачай `app-debug.apk` из релизов
2. Включи "Установка из неизвестных источников" в настройках Android
3. Установи APK
4. Разреши наложение поверх других окон
5. Запусти Clawd Pet

### Требования
- Android 7.0 (API 24) или выше
- Разрешение на наложение поверх других окон
- ~2 МБ свободного места

---

## Сборка

### Требования
- JDK 21
- Android SDK (API 34)
- Kotlin 1.9.0+

### Команды

```bash
# Клонировать репозиторий
git clone https://github.com/yourusername/clawd-pet.git
cd clawd-pet

# Собрать Debug APK
./gradlew assembleDebug

# Установить на устройство
./gradlew installDebug

# Собрать Release APK (требуется keystore)
./gradlew assembleRelease
```

APK будет находиться в `app/build/outputs/apk/debug/app-debug.apk`

## Технологии

| Компонент | Технология |
|-----------|-----------|
| **Язык** | Kotlin 100% |
| **UI** | Custom Canvas Rendering |
| **Архитектура** | Foreground Service + Overlay Views |
| **Физика** | Собственная система с гравитацией и инерцией |
| **Анимация** | Canvas-based 60 FPS |
| **Хранение** | SharedPreferences |
| **Сенсоры** | Accelerometer для наклона и тряски |

### Ключевые компоненты

```
app/src/main/java/com/clawd/pet/
├── PetEngine.kt          # Основная логика поведения и физики
├── PetRenderer.kt        # Рендеринг персонажа (пиксельная графика)
├── FxView.kt            # Отрисовка эффектов, частиц и UI
├── PetOverlayService.kt # Foreground Service и управление оверлеем
├── MainActivity.kt       # UI настроек
├── Prefs.kt             # Система настроек
├── Phrases.kt           # База фраз
└── Skins.kt             # Цвета, аксессуары, константы
```

## Особенности реализации

### Пиксельная графика
Питомец отрисовывается процедурно на Canvas с использованием пикселей, что позволяет:
- Динамическое масштабирование без потери качества
- Анимации в реальном времени (моргание, походка, эмоции)
- Минимальный размер приложения

### Физический движок
- Реалистичная гравитация и инерция
- Упругие отскоки от краёв экрана
- Плавные переходы между состояниями
- Адаптация под разные разрешения экрана

### Умное поведение
- Питомец избегает краёв экрана
- Самостоятельно находит путь к еде
- Реагирует на контекст (время суток, уровень батареи)
- Запоминает позицию между запусками

- Настройка частоты еды - три уровня скорости
